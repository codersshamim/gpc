About Global Postal Codes

Global Postal Codes is a postal code reference directory designed to help people find postal code information from countries and locations around the world.

You can explore available country and regional information, search by location, and find postal codes where data is available.

Our Mission

Our mission is to make postal code information easier to discover and use through a simple, accessible directory.

Data Accuracy

Postal information may vary by country and may be updated over time. Some locations have more complete data than others. Please confirm important address details with the relevant postal authority.
